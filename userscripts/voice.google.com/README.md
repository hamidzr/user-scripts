# Google Voice Latest Login Code

Shows the newest login or verification code from your Google Voice texts in a small floating card, so you can copy it with one click.

## What it does

- shows the newest verification or login code in a card at the bottom left of the page
- shows the sender and send time under the code
- click the card, or focus it and press Enter or Space, to copy the code
- hides codes older than an hour
- skips your own replies
- Option+Shift+C on macOS (Alt+Shift+C elsewhere) copies the code from anywhere on the page while a code is showing
- the chip on the card shows the shortcut for your OS; click it to turn the shortcut off or back on
- right-click the chip to switch between Mac and PC key names if detection guessed wrong
- the shortcut setting and key names are remembered per site in localStorage (`lb-otp-card-shortcut`, `lb-otp-card-key-style`)
