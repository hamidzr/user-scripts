# Google Messages

Latest login code: shows the newest verification / login code from Google Messages for web in a
small floating card. Click it to copy the code. Codes older than an hour are hidden.
Pinned conversations are skipped.

Press Option+Shift+C on macOS (Alt+Shift+C elsewhere) to copy the code from anywhere on the page.
The chip on the card shows the shortcut for your OS; click it to turn the shortcut off or back on,
or right-click it to switch between Mac and PC key names if detection guessed wrong. Both choices
are remembered.
